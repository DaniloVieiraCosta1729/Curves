# Creating mathematical curves and animation with raylib and webassembly

In this project I'll be trying to make a program that is capable of rendering curves and animations related to these curves.
As a use case, I'll create all the curves in chapter 1 of the book "Problems in Mathematical Analysis" by Demidovich and show them on an html page.

## Secondary goals

I may implement a parser for read curves from a file or from the CLI or even from the html page, but it can take some time due to my lack of time lately.
